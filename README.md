# Half-Second Menu
Ferdilanz' Half-Second Menu (or HS-Menu for short) is a LuaMenu using the AustinKregel's modified implementation of LoganW234's Lua-Bridge, along with Essentials Framework (Ess-Lib) to provide an internal, runtime, graphical menu with debug and cheat options. Ordnance Caller by Capt-Koala (Badga666)
## Origins
Half-Second Menu comes from my [All-In-One Spawn Menu](https://github.com/Ferdilanz/Mercenaries2-AllInOneSpawnMenu) where the main difference is that this is no longer just a spawn menu. This is a feature-complete cheat menu (euphemized to "Debug menu") that allows the player to spawn vehicles, NPCs, Supply Drops, Pickups, teleport to Collectible Toolboxes, add money, fuel, and a little bit more.
### This menu is handwritten and copied & pasted with zero input by AI.
