# Half-Second Menu
Ferdilanz' Half-Second Menu (or HS-Menu for short) is a LuaMenu using the AustinKregel's modified implementation of LoganW234's Lua-Bridge, along with Essentials Framework (Ess-Lib) to provide an internal, runtime, graphical menu with debug and cheat options.
